#
# karmavar.txt
#
# Controls display of karmas in character editor.
#
# format of each line is:
#
#   gvar, pic, name, description
#
# where:
#
#   gvar is the GVAR_* number for the variable corresponding to the karma.
#
#   pic is the number of the skilldex art (line number in art\skilldex\skilldex.lst)
#
#   name is the number of the message in editor.msg with the karma name.
#
#   description is the number of the message in editor.msg with the karma description.
#
